## Image generation today

Engine: ComfyUI behind llama-swap (`comfyui_auto`, reached at `/comfyui/`).

| Way in | Notes |
| --- | --- |
| Router passthrough | `http://127.0.0.1:8080/comfyui/prompt`, `/history`, `/view` with `Authorization: Bearer $LLAMA_SWAP_API_KEY`. ComfyUI's native API with workflow JSON from `workflows/<model>/`, not OpenAI-style `/v1/images/generations`. |
| Wrapper scripts | `./media-models/generate-<profile>.sh <args>`. The practical option. |
| CLI | `l3ms --run-profile media:<id> --task image --input ... --output-dir /abs/fresh/dir` |
| TUI task form | Raw API-format workflow JSON, needs Chat connected first, Ctrl+Enter runs. |

Constraints: cold start is about 246 s; requesting `/comfyui/` evicts the
resident LLM; a batch is one blocking call with no LLM request in between.
Details: [media through llama-swap](migration/media-through-llama-swap.md).

### Gap

There is no prompt-in, image-out surface. `docs/workbench-plan.md` plans an
Images playground tab with inline previews, but `src/` has none. Two options:

1. A thin `/v1/images/generations` shim that wraps the wrapper logic.
2. A TUI Images tab: prompt, profile picker, size and steps, result preview.
